# Nura V4.7 — Voz mais rápida + novos quebra-gelos

## Voz
- A primeira frase é enviada separadamente ao TTS para começar a tocar mais rápido.
- Enquanto a primeira frase toca, o restante da resposta é preparado em paralelo.
- As partes são reproduzidas em sequência, sem sobreposição.
- Mantém uma única sessão de voz ativa.
- Respostas foram encurtadas para soar mais naturais e reduzir espera.

## Quebra-gelo
Novos atalhos iniciais:
- É para mim
- Quero dar de presente
- Quero algo parecido

## Inteligência
- Novo campo `purpose` no perfil do cliente:
  - self
  - gift
  - similar
- A Nura lembra o objetivo e não pergunta novamente.
- Para uso próprio, pergunta referência/aroma.
- Para presente, investiga o gosto da pessoa presenteada.
- Para algo parecido, pergunta diretamente qual perfume será usado como referência.
